# ZERO PARADES: For Dead Spies 한글 패치 (비공식 팬 번역)

ZA/UM의 *ZERO PARADES: For Dead Spies*(Steam)의 비공식 한국어 번역입니다. 게임 내 언어 목록에서 중국어 자리가 **한국어**로 바뀌는 방식입니다.

- 번역 범위: 게임 안의 모든 글 — 대사·서술 약 6.7만 줄, 메뉴·UI·아이템·인물·효과 등 약 5천 줄, 총 72,717줄(한글 약 243만 자)
- 게임 버전: 1.1.40707 기준
- 상태: **베타(v0.9)** — 번역은 끝났고, 전체 플레이 검수가 진행 중입니다. 어색한 번역은 Issues로 알려 주세요.

## 설치 방법 (Windows)
1. [Releases](../../releases)에서 최신 `ZeroParades_KR_vX.X.zip`을 받아 압축을 풉니다.
2. `INSTALL.bat`을 실행합니다. 게임 폴더를 자동으로 찾고, 못 찾으면 폴더 경로를 입력하라고 안내합니다.
3. 게임 실행 후 **설정 → 게임플레이 → 텍스트 언어**에서 **한국어**를 선택합니다.

원래대로 되돌리려면 `RESTORE.bat`을 실행하거나 Steam에서 "게임 파일 무결성 검사"를 하세요. 설치할 때 원본 파일은 `backup_original` 폴더에 자동으로 백업됩니다.

## 이 패치가 바꾸는 것
- 텍스트 표(중국어 슬롯 → 한국어), 글꼴(한글 지원 Noto Sans CJK KR로 교체), 제목 로고 그림(중국어판 로고 → 영어 로고), 첫 화면 저작권 문구
- 한국어 줄바꿈 설정: 게임의 `resources.assets` 안에서 "한글 현대식 줄바꿈 규칙" 값 1바이트를 켜서, 문장이 단어 중간에서 끊기지 않고 띄어쓰기 위치에서만 줄이 바뀌게 합니다. 설치 파일(`INSTALL.bat`)이 사용자 PC에서 직접 고치며, 원본은 백업됩니다.
- 게임 실행 파일(exe)은 수정하지 않습니다. 게임 업데이트로 파일이 바뀌면 패치를 다시 적용해야 할 수 있습니다.

## 저장소 구성
| 경로 | 내용 |
|---|---|
| `translations/ko_dialogue.tsv` | 대사·서술 번역 (키 + 한국어) |
| `translations/ko_ui.tsv` | 메뉴·설정 등 UI |
| `translations/ko_misc.tsv` | 아이템·인물·효과·일지 등 |
| `LICENSE-NotoSansCJK-OFL.txt` | 글꼴 라이선스(SIL OFL 1.1) |
| `NOTICE.md` | 출처·저작권 고지 |

번역 파일에는 원문(영어)이 들어 있지 않고 키와 한국어만 있습니다. 게임 파일은 이 저장소에 포함되지 않습니다.

## 번역 방침
- 서술문은 평서체(~다), 인물별 말투를 유지합니다. 욕설은 원문 수위를 따릅니다.
- 스킬 이름: 그림자극, 인물론, 회색 뇌세포, 센서, 시학, 눈치, 담력, 기록, 본능, 청사진, 당성, 테크플렉스, 얽힘, 도플갱어, 협응
- 공작원(operant), 관리관(controller), 담당관(handler), 공작국(Operant Bureau), 문명 재단(Civilisation Trust) 등 용어집을 따릅니다.

## 알려진 한계
- 일부 말장난(영어 단어 놀이)은 한국어로 살리기 어려워 의역했습니다.
- 게임을 켠 뒤 Alt 키 힌트(뒤로 / 초기화 등)가 처음 뜰 때만 키 이름 상자가 잠깐 어긋나 보일 수 있습니다. 한글 글자 모양을 처음 만드는 동안의 현상이며 한 번 지나면 정상입니다.
- 스팀의 "게임 파일 무결성 검사"를 하면 패치가 제거됩니다. 다시 `INSTALL.bat`을 실행해 주세요.
- 게임 업데이트로 `resources.assets`가 바뀌면 줄바꿈 설정 수정은 자동으로 건너뜁니다(번역 자체는 적용됩니다).
